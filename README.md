# Arabic Learning App

An interactive React application for learning Arabic pronouns and demonstratives with a quiz-based approach.

## Features

- **Interactive Learning**: Learn Arabic pronouns and demonstratives with clear explanations and examples
- **Visual Aids**: Color-coded examples and visual representations to enhance learning
- **Quiz Mode**: Test your knowledge with interactive quizzes
- **Drag and Drop Interface**: Simply drag your answer to the question
- **Mobile-Friendly**: Works on both desktop and mobile devices
- **Accessible**: Built with accessibility in mind

## Lesson Content

The app currently includes the following lessons:

1. **Third-Person Pronouns** (ضمائر الغائب)
2. **First-Person Pronouns** (ضمائر المتكلم)
3. **Demonstrative Pronouns** (أسماء الإشارة)

## Technical Implementation

- Built with React (Hooks for state management)
- Uses CSS with Tailwind for styling
- Designed with RTL (Right-to-Left) support
- Implements drag-and-drop functionality
- Mobile-friendly with touch support

## Project Structure

- `ArabicLearningApp.jsx` - Main component
- `lessons-data.js` - Data for all lessons

## How to Run

1. Make sure you have Node.js and npm installed
2. Clone the repository
3. Install dependencies:
   ```
   npm install
   ```
4. Start the development server:
   ```
   npm start
   ```
